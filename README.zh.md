# dsh-download-indicator

在 DeepSeek Harness 的 Web 界面右上角显示下载进度的小浮窗 —— **半透明、可拖动，而且只在真有东西在下载时才出现**。

指给它一个或几个目录，它就会盯着里面的大文件：只要某个文件还在变大，浮窗就淡入右上角，显示进度条、已下载量和**实时速度**；一旦没有文件在增长，它就淡出，不占你的视线。

常见场景不需要任何配置 —— 默认监控 `F:\ComfyUI\models` 和 `F:\training\downloads`。

## 安装

```sh
dsh plugin --profile desktop add dsh-download-indicator
```

安装后需要**重启一次客户端**（桌面壳在启动时才收集注入表），如果页面已经开着再刷新一下即可。

## 特性

- **只在需要时出现** —— 每 2 秒轮询一次，连续两次没有活跃下载就淡出隐藏。
- **可拖动** —— 按住浮窗任意位置拖到不挡事的地方。位置存在 `localStorage` 里，刷新和重启都不会丢。
- **实测速度** —— 服务端比较两次采样之间的文件大小，速度是量出来的而不是猜的；最近三次取平均，读数不会乱跳。
- **自动发现** —— 不需要逐个声明下载任务。它递归扫描监控目录（深度 ≤ 3），筛选 20 MB 以上、扩展名属于常见模型/压缩包的文件，只报告正在增长的那些。
- **拖不出屏幕** —— 边界有约束；窗口缩放导致浮窗跑到外面时会自动拉回可见区域。
- **总速度** —— 标题栏右侧显示所有活跃下载的合计速度。
- **没有总大小时也不含糊** —— 用流动条纹进度条加已下载量表示，而不是编一个假百分比。

## 配置

全部可选。

| 变量 | 默认值 | 含义 |
|---|---|---|
| `DSH_DOWNLOAD_WATCH` | `F:\ComfyUI\models;F:\training\downloads` | 要扫描的目录，分号分隔 |

用于算百分比的已知总大小在 `lib/index.js` 的 `KNOWN_TOTALS` 里，键是小写文件名。认不出的文件就不显示百分比，其余照常。

如果环境不同，可以调 `lib/index.js` 顶部的几个常量：

```js
const MIN_SIZE = 20 * 1024 * 1024   // 小于这个大小的文件忽略
const MAX_DEPTH = 3                 // 目录扫描深度
const MIN_GROWTH = 128 * 1024       // 增长超过多少才算「在下载」
```

## 实现要点

分成两部分，因为桌面客户端只接受一种注入方式：

1. **服务端**（`lib/index.js`）在 DSH 的 web server 上注册两个路由 —— `/dsh-download/status`（JSON：活跃下载、大小、速度）和 `/dsh-download/widget.js`（客户端脚本），并推一条结构化注入行让脚本被加载。
2. **客户端**（`assets/widget.js`）负责建浮窗、轮询状态、渲染。

注入**刻意用内联 `script` 行而不是 `script-src` 行**：`script-src` 一旦加载失败会 reject 整个客户端启动，路由万一不在就等于把整个界面拖垮。内联行自己创建 `<script>` 标签并吞掉 `onerror`，所以这个插件**永远不可能阻止客户端启动**。

## 卸载

```sh
dsh plugin --profile desktop remove dsh-download-indicator
```
